# Amostragem Sistêmica
Aplicação web desenvolvida com **HTML, CSS e JavaScript** para realização de amostragem sistemática. O usuário informa o tamanho da população (**N**) e o tamanho da amostra (**n**), e o programa retorna os **n índices selecionados**, no intervalo de 0 a **N − 1**, que devem compor a amostra.

🌐 [Acessar aplicação](https://icaro2003.github.io/amostragem-sistemica/)
